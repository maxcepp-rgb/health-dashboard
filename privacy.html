Privacy Policy

Health Dashboard is a personal tool used only by its owner. This policy explains how it handles data.

What it accesses

With the owner's permission, it reads the owner's activity, sleep, heart and body measurement data from the Google Health API using read-only access. It never writes or changes any data.

Where the data goes

Data is stored only on the owner's own computer, where it is used to build a private dashboard page. It is not uploaded to any server, sold, shared with third parties, or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, and the locally stored data can be deleted by removing the dashboard's folder.
